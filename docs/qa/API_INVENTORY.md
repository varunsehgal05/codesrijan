# API inventory
Date2026-11-02. 194 actual app route registrations found in server.js and role-portals.js. Template routes register per role and are shown as source expressions. Source duplicates may exist; first registered matching handler controls Express behavior.

The accompanying API_INVENTORY.json records method, path, source line, middleware expression, detected database methods and literal error codes. Validation detection is a search aid, not proof of correctness. Request/response schema details remain in the referenced handlers. No handler source or secrets copied.

Individual endpoint execution is NOT RUN unless explicitly evidenced in SECURITY_EXECUTION, ADMIN_EXECUTION, STUDENT_EXECUTION or PUBLIC_EXECUTION. Passing a grouped test does not clear every route. No destructive production security/load test performed. Original267-ID mapping awaits attachment.
